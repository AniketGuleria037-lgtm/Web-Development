Different units of heights

This Height uses vh and vw. vh is 1% of viewport height. And vw is 1% of viewport width

This unit is em. em is the unit relative to the parent class. If the parent class has 20px of font size. So if i set the height of child class the be 2em. Its height would be 40 px

The rem does not depend on the parent font size but sticks to the root html font size. The default font size of font siz eof root html is 16px. So any size of 2rem will be 32px
